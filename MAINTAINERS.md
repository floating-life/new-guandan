# Maintainers

`new-guandan` is currently maintainer-led.

## Primary maintainer

- [@floating-life](https://github.com/floating-life) — project direction, architecture, release decisions, code review, evaluation integrity, and security triage.

## Maintainer responsibilities

The maintainer is responsible for keeping the rules engine correct, preserving the fair-play boundary for hidden information, reviewing changes to AI/evaluation logic, maintaining reproducible verification, and deciding when experimental strategies are eligible for release.

External contributors are welcome through issues and pull requests. As the contributor base grows, this file will be expanded to document additional maintainers and decision-making responsibilities.
