    掼蛋规则摘要

    基本设置

    • 两副牌 108 张，4 人，对家为队友（你 + 对家 AI 为一方）。
    • 每人 27 张，先出完为头游，最后为末游。
    • 从 2 打到 A，先打过 A 的一方获胜。

    级牌与逢人配

    • 当前级数对应的牌为级牌，单张/对子等比 A 大、比王小。
    • 两张红桃级牌为「逢人配」，可当任意非王牌使用。

    牌型（第一类互压须同型）

    • 单张、对子、三同张、三带二、顺子（5 张）、三连对、钢板（二连三）。
    • A 在顺子/连对/钢板中可作 1 或接 K。

    炸弹类（可压任意第一类）

    • 天王炸（两大两小）> 六张及以上炸弹 > 同花顺 > 五炸 > 四炸。
    • 同张数炸弹比点数；同花顺之间比点数。

    出牌与借风

    • 领出任意牌型，其余用更大同型接，或用炸弹类压制；都可过牌。
    • 其余在局者都过后，最后出牌者领出下一圈。
    • 出完后若无人再压，由对家借风领出。

    升级（头游方）

    • 头游 + 二游（双上）→ 升 3 级
    • 头游 + 三游 → 升 2 级
    • 头游 + 末游 → 升 1 级
    • 败方不升级；级数从 2 打到 A，升到 A 后争夺过 A。
    • 打 A：双上或头三可过 A 获胜；头末不过 A。连续三次不过 A 打回 2 级。

    进贡 / 还贡 / 抗贡

    • 第二副起：末游（或双下两人）向赢家进贡最大牌（逢人配除外）。
    • 赢家还一张：有不大于 10 的非级牌时必须从中选择，否则还当前最小牌；进贡方先出。两张大王可抗贡，由头游先出。

    训练功能

    • 难度：简单 / 普通 / 困难 / 大师。大师模式强化公开牌史记忆、牌型规划、搭档配合与残局控制，不读取其他玩家未公开手牌。
    • AI策略：本地 AI 默认离线；智能增强仅在关键/有歧义回合请求云端。超时、429、5xx 和网络波动只回退当前手并自动重试；密钥、模型或协议错误才转为全场景本地 AI。
    • 云端隐私：每次仅发送当前电脑玩家自己的手牌、合法候选和公开牌史，不发送其他玩家暗牌；但整局多次调用可能让第三方服务累计看到多名电脑玩家手牌，请同时遵守所选 API 服务商的数据保留政策。
    • 教练模式：轮到你时给出推荐出法（按困难 AI 思路）。
    • 出牌评价：每次操作打分；副末复盘；历史牌技统计。
    • 复盘：查看最近对局出牌流水与评分。

    云端 API 设置

    密钥只发送到本机 127.0.0.1:20801，不会写入浏览器存储；保存后由 Windows 当前用户的 DPAPI 加密保存在本机，重启服务仍可使用。留空表示保留同一服务商的当前密钥，更换服务商时必须填写对应新密钥；保存后会立即重新检测。
